### Behind the code

I'm **Muhammad Alif Daniel**, a full-stack web developer based in **Malaysia**. I turn real-world requirements into practical web applications, with an eye for thoughtful interfaces and clean architecture.

My work spans frontend experiences, backend services, and the undocumented legacy systems that need a little patience to untangle. Away from work, I run a self-hosted homelab to get hands-on with deployments, backups, and service recovery.
