# Shared project presentation

Follow the [portfolio presentation rules](https://github.com/ALXP-DANIEL/PORTFOLIO/blob/main/docs/project-presentation.md).

Run `python3 scripts/build-project-bento.py` after updating an owning repository. It reads each `project.json`, fetches `profileImage`, and rebuilds the composite with consistent padding, gutters, baselines, and arrows. Changes are published only when the generated SVG is committed and pushed.
